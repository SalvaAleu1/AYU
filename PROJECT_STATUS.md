# AYU Platform — Development Checkpoint

This file is the internal build checkpoint for the Apuk Youth Union in Juba (AYU-Juba) platform.

## Continuity rule

- Work proceeds in blocks of exactly three roadmap phases when the user says **Continue**.
- Do not skip, merge, reorder or advance beyond the next three phases unless the user explicitly changes the scope.
- At the end of every build block, update this checkpoint with completed phases and the next three phases.
- AYU and Apuk Graduates Congress (AGC) are separate organizations. AGC may appear in AYU only where AYU's Constitution identifies it as a partner institution.
- Public production UI must not contain placeholders, developer notes, README instructions, fake statistics, fabricated news, invented leadership details or descriptions of private verification processes.
